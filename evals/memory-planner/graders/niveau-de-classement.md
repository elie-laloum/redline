# Classe-t-il au niveau le plus haut ou ca reste vrai ?

## Reussite
- La prop du `date-picker` va dans `repos/design-system/`, pas dans `changes/`
- Le mode de publication du design system va dans `repos/design-system/` ou
  `capabilities/`, pas dans un fichier de ticket
- Le chevauchement d'exercices, **non tranche**, n'est pas ecrit comme un fait acquis
- Chaque operation dit **pourquoi ce niveau**

## Echec
- Tout range dans `changes/FT-1025.md`
- Une question ouverte notee comme une reponse
- Une note qui recopie une signature de fonction, perimee au prochain refactor
