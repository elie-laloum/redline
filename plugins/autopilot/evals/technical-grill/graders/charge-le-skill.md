# Charge-t-il le skill du repo, et s'en sert-il ?

## Reussite
- Le skill de `design-system` est lu et cite
- L'agent **ne demande pas** comment creer ou etendre un composant : le skill le dit deja
  (prop optionnelle avec valeur par defaut, jamais d'extension pour un cas particulier)
- Le mode de publication (tag annote, CI) est repris de la, pas invente

## Echec
- Une question dont la reponse est ecrite mot pour mot dans le skill
- Une convention de publication proposee d'apres une habitude generale
